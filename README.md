## 👨‍💻 About Me

I'm **Leon Sony** — a Linux and Android developer building projects around operating systems, ROM development, desktop Linux, system tooling, and apps.

I like taking an idea all the way through:

```text
IDEA → SOURCE → BUILD → BOOT → TEST → TUNE → SHIP
```

My projects range from **AOSP / Android x86 work** and **custom ROM ecosystems** to **Arch-based Linux distributions** and **Android TV applications**.

> **Build. Break. Improve. Repeat.**
