## About

**JacksonTech** is the project identity behind the software I build and maintain.

I work primarily around Linux, Android, custom operating systems, device bring-up, system tooling, and desktop UX.

Current work includes **CathodeOS**, an Android 16-based x86_64 PC operating system, and **Calypso Linux**, an Arch-based Linux distribution focused on a polished desktop experience.
