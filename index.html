Hi, I'm Leon.

I'm an Android developer working across apps, Android TV, platform experiments, and open source.

I do some ROM and device work too, but that is not the main thing I want to be known for. Android development is the center; the systems rabbit holes are what happen when curiosity gets involved.

My favorite workflow is pretty simple: idea → code → build → boot → something breaks → figure out why → fix it → make it nicer.

I build to learn. Then I polish what I learned into something worth keeping.
